# A Night to Nourish website

The site for a-night-to-nourish.org, hosted free on GitHub Pages.

- `index.html` holds the whole page (text, styles and the small script).
- `images/` holds the logos and artwork.
- `CNAME` tells GitHub Pages to serve the site at a-night-to-nourish.org. Don't delete it.

To change the site, edit `index.html` on GitHub (pencil icon) and commit. The live site updates in a minute or two.

The contact form uses Formspree. Replace `YOUR_FORM_ID` in `index.html` with the ID from your form at formspree.io.
